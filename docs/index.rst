UltraZohm CPLD
==============

Firmware and tooling for UltraZohm D-slot ``LCMXO2-2000HC-4TG100C`` and S3C ``LCMXO2-4000HC-4TG144C`` devices.
Choose the user guide to build and program existing firmware, or the developer guide to change programs and tooling.
Each guide starts with a quick start reference.
