Developer guides
================

Choose the guide for the work you want to do.

* :doc:`toolchain`: contribute to Python commands, build backends, simulation infrastructure, documentation tooling and CI.
* :doc:`hdl`: create and validate programs by writing VHDL or using the CSV/TOML generator.

Both guides include a quick start reference.
For building and programming existing firmware, see :doc:`../user/index`.
